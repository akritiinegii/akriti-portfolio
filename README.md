# Akriti Negi Portfolio

A clean, responsive React + JavaScript + CSS portfolio inspired by the supplied reference.

## Run in VS Code

1. Open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Run:
   npm install
4. Then run:
   npm run dev
5. Open the localhost address shown by Vite (usually http://localhost:5173).

## Main files

- `src/App.jsx` — all React components and portfolio content
- `src/styles.css` — complete design, colors, responsive layout and animations
- `public/akriti-profile.jpg` — your uploaded profile photo

## Replace links

Inside `src/App.jsx`, replace the `#` links in project cards with your real GitHub/live-demo URLs.

The LinkedIn link is also a placeholder because a LinkedIn URL was not provided.

## Change your profile photo

Replace `public/akriti-profile.jpg` with another image using the same filename.
